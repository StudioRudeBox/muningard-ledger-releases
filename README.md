# Muningard Ledger

A local-only desktop bookkeeping app built by Studio Rude Box. Covers clients/suppliers, invoices, quotes, expenses, recurring expenses, a depreciation/asset register, a client expirations register, and quarterly Dutch VAT reporting.

This repository hosts release builds only — installers and release notes.

## Download

Grab the latest installer from the Releases page:

- **Windows**: `Muningard Ledger-Setup-<version>.exe`

Run the installer and follow the prompts. The app installs per-user and creates Start Menu / Desktop shortcuts.

## Data & privacy

Muningard Ledger runs entirely on your machine — there is no cloud sync, no telemetry, and no external account. All bookkeeping data is stored locally in a SQLite database file.
